# Next serial layout experiment: ownership, traffic, and measurement

Keep the canonical 12E-byte AoS tuple array. A separately admitted grouped owner borrows the exact prepared topology; numerical weights remain in the current frame. One offset array needs V+3 usize entries. Factor 0 groups use contiguous canonical tuple ranges. Factors 1/2 use one 2E-entry tuple-ID array with deterministic stable counting placement; choose u32 only when every tuple ID fits, otherwise checked usize/64-bit. Each row's tuple IDs remain ascending in original canonical order. Temporary cursors need at most max(n1,n2) usize entries, separately charged at construction. All sums/reservations and old/new overlap must be admitted before allocation; test both index-width paths without allocating more than 2^32 entries.

Compare three kernels on the same inputs. Scalar AoS scatter remains the control. Grouped row gather computes each coefficient in a local accumulator, avoiding write conflicts and P*V worker buffers, but revisits tuple/weight/image operands per factor. Two-pass tuple-image plus grouped reduction computes weighted tuple images once, at the cost of 8E bytes per lane and an extra streaming pass. Retain per-row addition order; do not algebraically reassociate x0+x1+x2, MAP's mul_add coupling or weight products. Equal final coefficients alone do not excuse changed action counters, setup or memory.

At cache-resident V the added indices/reloads can dominate, so do not default to grouping from nominal byte counts. With large V, random coefficient output traffic can dominate scatter. Profile actual complete solves, then isolate incidence, adjoint, Gramian, MAP, transfers, certificate, projection and Krylov reductions in a separate diagnostic run. Timing hooks must be absent from authoritative benchmark builds. Report warm steady application and cold setup separately, and keep complete setup+solve+certification+output as the acceptance surface. Enlarge development-only dimensions/degree skew beyond the M4 V384 case before choosing a layout; commit a separate policy and preserve all families/seeds/settings.

The grouped representation must serve later M7 row-owned parallel actions and M8 panels. Balance partitions by tuple count; declare hub segments and combine their partials in fixed order. Keep scalar mode and cross-RHS concurrency available without mandatory grouping. Avoid oversubscribed inner workers and floating-point atomics. Panel loops should use const widths 2/4/8 and coordinate-major lane-minor vectors, while each lane retains independent Krylov recurrence, certificate, retirement and tail handling. Memory economics include the two LSMR history windows per lane.

M5a precedes this experiment. Flat arenas, fused prolong-add, fused weighted incidence and exact-RHS certificate-reference caching remain individually reviewable opportunities. No selector or new default is justified until measured on the declared balanced development matrix; calibration/holdout and immutable upstream executable comparisons remain later gates.
